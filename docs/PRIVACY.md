# 隐私与发布范围

## 应用处理的数据

- 通过本机 Codex CLI 读取账户标识、用量周期、剩余额度与可用重置次数。CLI 自行处理登录，应用不直接读取或复制 token。
- 只有明确确认“续一杯”才提交重置；查询和取消不会消耗次数。
- 本工具的最近一次重置结果在本机按账户保存，包含账户标识、操作 UUID、时间和结果，不包含登录凭据。
- 应用侧没有接入分析统计、第三方遥测或自动上传日志；Codex CLI 自身行为由其实现和账户设置决定。

## 1.2.8 / build 14 清理

- 应用标识使用 `app.codexccino.menubar`，不再包含开发账号。重置记录目录仍保持兼容。
- README 与其他说明采用通用命令，不硬编码个人账号、仓库地址或工作目录。
- Git 历史整理为干净的初始提交，提交作者、提交者与版本标签作者均使用项目身份；旧文档和个人作者不属于当前可达历史。
- 图标母版和 ICNS 移除生成溯源、EXIF、文本等非显示元数据；保留全部解码像素、透明通道和尺寸。JPEG 照片与文档截图不含 EXIF / XMP / IPTC，蒸汽 PNG 仅包含图像与透明度数据。
- 安装包只包含运行必需文件，不包含构建缓存、调试符号、图标母版、账号记录或本地检查输出；ZIP 不携带扩展属性和额外所有者字段。
- 跟踪文件、当前可达提交 / 标签及安装包均检查已知个人身份、个人绝对路径、其他私有仓库 / 内网站点、常见访问令牌和私钥格式。文档截图使用离线演示数据。
- 本机配置、账户记录、旧安装包、恢复备份和检查报告通过忽略规则排除，不推送到仓库。

## 范围与限制

检查针对上述文件和当前可达历史，不能证明所有未知格式或未来提交都绝不存在个人信息。仓库是否公开以 GitHub 页面当前设置为准。

GitHub 页面会显示仓库归属账号、Release 发布账号及相关平台活动；这些平台身份不能通过修改项目文件隐藏。

清理前仓库曾公开。历史重写不会追回其他人的克隆、分叉或已下载附件；GitHub 可能按旧提交 SHA 保留缓存视图。需要彻底清除托管缓存时，应联系 GitHub Support，由平台判断是否符合删除条件。参见 [GitHub 移除敏感数据说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。

已有本地克隆应重新克隆，或把必要改动移植到干净历史上；不要把旧分支直接合并回来。
